Approval

Approval is recorded with the reviewer's identity and both rules hashes. If either venue edits its rules afterwards, the pair is automatically suspended. There is no acknowledgement override: a pair with an unapprovable reason above cannot be approved through this endpoint at all.

curl -X POST localhost:8000/api/pairs/{{ pair.id }}/approve \
  -H 'content-type: application/json' \
  -d '{"approved_by":"you@example.com","reviewer_notes":"...",
       "kalshi_settlement_source":"","polymarket_settlement_source":""}'

The settlement-source fields record an authoritative source you obtained outside the API. Supply them per leg: two unknown sources are two unknowns, not agreement.
